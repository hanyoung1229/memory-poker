# GAME CLUB v1.10.9 — 친구들과 즐기는 멀티플레이 기억력 포커

별도의 패키지 설치 없이 **Node.js 20 이상**에서 실행하는 실시간 링크 초대형 게임입니다.
브라우저에서 1명이 방을 생성하면 `/r/ABC123` 형태의 링크가 생기며,
친구들이 그 링크로 참가해 각자의 휴대폰/PC에서 동시에 플레이합니다.

## v1.10.9 — 머리 위 게이지는 남은 점프 제한시간

- 개구리 머리 위 게이지는 정답 점프마다 100%로 충전되며 제한시간이 흐를수록 줄어듭니다. **게이지 0%가 되면 즉시 아웃**입니다.
- 첫 점프 후 전체 30초 타이머, 점수별 점프 제한시간, 5칸 미리보기 및 기존 랭킹은 유지합니다.

## v1.10.8 — 점프 시간 게이지 충전형으로 반전

- 개구리 머리 위 게이지는 비어 있는 상태(0%)에서 출발해 시간이 지날수록 100%까지 차오릅니다. 정답 점프에 성공할 때마다 다시 비워지고, 완전히 차오르는 즉시 아웃됩니다.
- 전체 30초 제한, 점수별 점프시간 수식 및 기존 조작과 랭킹을 유지합니다.

## v1.10.7 — 개구리 머리 위 점프시간 게이지

- 점프별 제한시간 숫자/상단 막대를 없애고 개구리 머리 위에 감소하는 게이지를 배치했습니다. 정답 점프마다 게이지가 다시 가득 차며, 0이 되면 아웃됩니다.
- 전체 30초 제한시간은 상단 TIME LEFT 숫자와 별도 막대로 유지합니다. 첫 점프 시작, 점수 연동 시간 수식과 5칸 미리보기는 동일합니다.

## v1.10.6 — 전체 30초 + 점프별 제한시간 동시 적용

- 첫 점프 시 **전체 30초 제한**과 점프별 제한시간이 동시에 시작됩니다. 전체 제한시간은 점프해도 초기화되지 않습니다.
- 점프별 제한시간은 기존 수식 `max(0.2, 1.0 × 0.85^(4 × 점수/100))`을 그대로 적용하며, 성공 시에만 다시 시작됩니다. 어느 제한시간이든 먼저 만료되면 즉시 아웃입니다.
- 화면에 전체 30초 타이머와 점프별 타이머를 분리 표시하고 종료 원인을 구분합니다.

## v1.10.5 — 점프별 점수 연동 제한시간

- 총 30초 제한을 제거하고 **점프 사이 제한시간**으로 변경했습니다. 첫 점프 전까지는 타이머가 멈춰 있으며, 정답 점프를 할 때마다 다음 입력 마감시간이 새로 시작됩니다.
- 제한시간(초) = max(0.2, 1.0 × 0.85^(4 × 점수 / 100)). 잘못된 방향을 누르거나 다음 발판으로 제때 이동하지 못하면 종료합니다.
- 5개 발판 미리보기, 즉시 입력, 확률 상한 68%, 최고점 및 서버 1위 랭킹은 유지합니다.

## v1.10.4 — 갈림길 점프 30초 제한

- 갈림길 점프 제한시간을 **45초에서 30초**로 단축했습니다. 첫 방향 조작 시 카운트다운 시작, 5칸 미리보기, 즉시 입력, 최대 68% 확률 및 랭킹 기능은 유지합니다.
- 화면 타이머, 안내 문구, 게임 종료 메시지와 테스트를 30초에 맞게 갱신했습니다.

## v1.10.3 — 갈림길 점프 5칸 미리보기

- 점프 방향 미리보기를 4칸에서 **5칸**으로 늘리고, 화면에 발판 5개가 겹치지 않도록 원근 배치를 조정했습니다.
- 입력 지연 없음, 첫 점프 시 타이머 시작, 45초 제한, 확률 최대 68%, 기존 랭킹 기능은 그대로 유지합니다.
- 게임 엔진 및 관련 테스트를 5칸 미리보기 기준으로 갱신했습니다.

## v1.10.2 — 갈림길 점프 연못 배경, 서버 1위 기록, 첫 조작 시 타이머 시작

- 그린 테이블 점프 화면의 어두운 숲 느낌을 **맑은 연못과 연한 하늘색**으로 변경합니다. 수면 반사, 물결, 연잎, 수풀, 갈대와 양쪽 풀섬을 추가하고, 발판과 캐릭터는 대비를 유지하도록 색을 조정했습니다. 기존 45초 규칙과 즉시 입력 및 확률 최대 68% 규칙은 유지합니다.
- 점프 게임의 상단에 **그린 테이블 1등(닉네임 및 점수)**을 표시합니다. 닉네임 입력을 지원하고, 게임 종료 시 기록을 `/api/jump/leader`에 제출합니다. 기존 최고점보다 높을 때 서버의 JSON 파일(`.data/jump-ranking.json`)에 저장하고 다른 사용자에게 표시합니다. 로컬 최고점 표시는 기존대로 유지합니다.
- 서버 1위 점수는 **단일 Render 인스턴스의 로컬 파일**에 저장됩니다. 무료 Render 환경의 임시 디스크에선 재배포·재시작 또는 인스턴스 변경 후 기록이 초기화될 수 있습니다. 영구 저장, 여러 인스턴스 공유 및 조작 방지 기록 검증은 별도 데이터베이스/서버 검증을 추가해야 합니다.
- **게임 시작 버튼**은 조작 준비만 하고 타이머를 실행하지 않습니다. A/D 또는 ←/→ 또는 화면 방향 버튼으로 **첫 점프를 실행하는 순간부터 45초 카운트다운**이 시작됩니다.
- 랭킹 저장 유효성, 타이머 첫 조작 시작 및 연못 스킨/1등 영역 테스트를 추가했습니다.

## v1.10.1 — 그린 테이블 점프 조작 즉시 처리 및 연속 확률 상한

- 갈림길 점프의 매 착수 후 **220ms 입력 잠금**을 제거했습니다. A/D·좌우 방향키 또는 모바일 버튼을 누르는 즉시 정답/오답을 처리하고 다음 발판을 보여줍니다. 점프 모션은 짧게 115ms 재생되지만 다음 입력은 모션 종료를 기다리지 않습니다.
- 오답이면 즉시 종료합니다. 게임 내 타이머는 여전히 45초이고 방향 선택 정답 +1점, 최대 4발판 미리보기, 로컬 최고점 기록을 유지합니다.
- 발판 생성에서 동일 방향 **4회 연속부터 확률 상승을 멈춰 최대 68%**로 제한합니다. 기본 50%, 2연속 56%, 3연속 62%, 4연속 이상 68%; 반대 방향이 생성되면 50%로 복귀합니다.
- UI 확률 안내도 4연속 최대 68%로 갱신했습니다. 동작 테스트에 연속 20회 즉시 입력과 확률 상한을 추가했습니다.

## v1.10.0 — 그린 테이블 1인 점프 게임 「갈림길 점프」 추가

- **여섯 번째 게임** `/jump`를 게임 클럽에 추가했습니다. 기존 기억포커 초록 테이블과는 별도로 신규 **GREEN TABLE**을 추가해 대기실·로그인 없이 브라우저에서 즉시 도전합니다.
- 2갈래 길에 각각 **왼쪽 또는 오른쪽 한 곳만 발판을 생성**하며, 다음 발판 **4개**를 미리 확인할 수 있습니다. 게임은 끝없이 새로운 발판을 생성하며 **45초 안에 얼마나 많은 발판을 밟았는지** 1점 단위로 기록합니다.
- **A / 왼쪽 화살표**로 왼쪽 점프, **D / 오른쪽 화살표**로 오른쪽 점프합니다. 모바일은 화면 아래 버튼으로 조작합니다.
- 생성 확률은 첫 발판에서 왼쪽·오른쪽 각각 50%, 같은 방향이 연속으로 생성되면 **다음 생성에서 같은 방향 확률을 6%포인트 누적**합니다(2회 연속 뒤 56%, 3회 연속 뒤 62%). 반대쪽으로 생성되면 50%로 초기화하고, 100% 이상은 100%로 제한합니다.
- 정답 방향으로 점프하면 **+1점**, 틀린 방향은 즉시 게임 종료됩니다. 45초가 지나도 종료하며 결과에 이번 점수와 최고점수를 표시합니다. 아이템은 없습니다.
- 녹색 레인과 4개의 원근감 있는 발판, 개구리 점프 애니메이션, 점수판/타이머, 재도전 기능을 추가했습니다. 최고점수는 브라우저 저장소에 보존하며 서버 계정·실시간 동기화·결제는 필요하지 않습니다.
- 규칙/확률/점수/종료 및 파일 연결 관련 테스트를 추가했습니다. 기존 다섯 게임의 룰은 변경하지 않았습니다.

## v1.9.8 — 초대코드 자동배정 및 준비실 팀·관전석 자유 이동

- 십이장기 초대 코드 참가 시 선수/관전자 선택 메뉴를 삭제하고 닉네임만 입력해 자동 입장합니다. **빈 청팀(선공) → 빈 홍팀(후공) → 관전석(최대 3명)** 우선순위를 적용합니다. 빈 팀 여부로 판단하므로 기존 선수가 진영을 변경한 뒤에도 적절한 빈 팀에 새 참가자가 배정됩니다.
- 진행 중 대국에 새로 참가하면 관전자 자리로 자동 입장하며, 진행 중에는 팀을 변경할 수 없습니다.
- 준비실에서 청팀/홍팀/관전석 중 원하는 자리로 이동할 수 있습니다. 선수끼리 팀 교환은 기존대로 허용하며, 관전자는 비어 있는 팀에 입장할 수 있습니다. **관전자는 이미 사용 중인 선수 자리를 일방적으로 빼앗을 수 없습니다.** 선수는 관전석에 여유가 있을 때 관전자로 전환할 수 있습니다.
- 팀 또는 역할 변경 시 양 선수의 준비 상태를 초기화하고, 방장이 관전석으로 이동하면 남아 있는 선수에게 방장 권한을 넘깁니다. 이전의 초대 인증 토큰은 바꾸지 않으므로 동일 사용자가 계속 접속할 수 있습니다.
- 선수 2명+관전자 3명 정원, 실시간 관전, 30초 착수 제한, 무르기, AI 3/5/8수 및 기존 네 게임은 변경하지 않았습니다.
- 게임 로직·권한·준비실 UI 등 관련 테스트 총 40개 통과.

## v1.9.7 — 십이장기 어려움 AI 탐색 깊이 8수

- 어려움 난이도의 목표 탐색 깊이를 **7수에서 8수**로 변경했습니다. 쉬움 3수 및 중간 5수는 유지합니다.
- 어려움 AI의 기존 **4.5초 계산시간 및 24만 노드 제한**은 유지합니다. 복잡한 국면에서 8수 탐색이 완료되지 않으면 반복 심화 탐색에서 마지막으로 완성된 깊이의 결과를 사용합니다.
- 난이도 선택 화면은 **쉬움 / 중간 / 어려움** 표시를 그대로 유지하며, Web Worker 계산, 30초 착수 제한, 기존 게임 규칙은 변경하지 않았습니다.
- 목표 깊이와 계산 제한 관련 테스트를 8수 설정에 맞춰 갱신했습니다.

## v1.9.6 — 십이장기 말의 중복 이름 제거 및 난이도 표기 간소화

## v1.9.5 — 십이장기 AI 탐색 3/5/7수 및 차례당 30초 제한

- AI 선택 난이도의 목표 탐색 깊이를 **쉬움 3수 / 보통 5수 / 어려움 7수**로 변경했습니다. 사용 가능한 합법 수를 바탕으로 단계별 반복 심화 탐색, 알파베타 가지치기, 포지션 캐시·착수 정렬을 사용합니다.
- 깊은 수읽기는 **Web Worker 별도 스레드**에서 처리해 모바일의 말판 및 타이머 UI가 연산 때문에 멈추지 않게 합니다. 무르기·새 게임·모드 전환 시 진행 중인 AI 작업을 취소합니다.
- 단말 성능·국면의 경우의 수에 따라 탐색 목표 깊이 완료 전에 시간/노드 제한에 도달하면 **마지막으로 전체 탐색이 완료된 깊이의 수**를 채택합니다. 실제 도달 깊이와 조사 노드 수를 화면에 표시합니다.
- 선수 차례마다 **30초**를 새로 부여합니다. 온라인은 서버 기준 마감 시각과 서버 타이머로 판정하고, 관전자도 남은 시간을 확인합니다. 혼자 하기는 플레이어와 AI 모두 차례당 30초 제한을 적용합니다.
- 제한시간을 초과하면 해당 선수는 시간패로 처리합니다. 온라인 무르기를 요청한 동안에는 양측 시계를 일시 중지하고 수락·거절 또는 요청 취소 이후 새 30초를 시작합니다.
- Web Worker 미지원 환경은 사용자 경험을 위해 짧은 제한의 메인 스레드 탐색으로 대체합니다.
- 기존의 선수 2명+관전자 3명 구성, 팀 변경, 포로 말판 아래 배치 및 모든 이전 게임은 유지합니다.

## v1.9.4 — 십이장기 온라인 청팀·홍팀 변경과 관전석 3자리 추가

- **이동 방향 교정:** 말판의 오른쪽 아래 **5시 방향에서 출발**하며, 오른쪽 변을 따라 오른쪽 위 → 왼쪽 위 → 왼쪽 아래 → 출발점으로 **반시계 방향**으로 돌아갑니다. 지름길 대각선 좌표도 새 방향에 맞췄습니다.
- **준비실에서 청팀·홍팀 이동:** 각 플레이어가 자신의 팀을 자유롭게 변경할 수 있습니다. 팀 변경 시 모두의 준비 상태가 초기화되고, 1대1은 1:1, 1대2는 1:2(양방향 허용), 2대2는 2:2로 팀 구성이 맞아야 시작할 수 있습니다.
- 팀에서 혼자 남아 윷을 맡으면 2개, 두 명이 속하면 각각 1개를 맡도록 동적으로 자동 조절합니다. 네 명의 윷을 합계 4개로 판정하는 규칙을 유지합니다.
- 하얀 테이블 디자인의 대비·말판·이동방향 화살표·팀 선택 버튼·윷 판정 안내·승부 조작 영역을 강화했습니다.
- 기존 팀당 말 2개/4개 설정, 비밀 선택, 업기/잡기, 초대 코드, 나머지 두 포커 게임은 유지합니다.

## v1.6.3 — 카드 공개 카운트다운, 2배 카드, 자동 시작, 누적 판단시간

- 두 사람이 모두 준비를 마치면 **5초 카운트다운을 표시하고 자동 시작**합니다. 준비 취소 시 카운트다운도 취소합니다.
- 콜을 하면 서버가 **3초 카운트다운**을 시작합니다. 양쪽에 동일하게 3 → 2 → 1이 표시되며, **두 카드 사이 가운데** 큰 숫자로 나타납니다.
- 카운트다운이 끝나기 전에는 두 카드 정보가 브라우저에 전송되지 않습니다. 카운트다운이 끝난 후 **기존보다 가로·세로 약 2배 큰 카드**를 동시에 공개합니다(모바일은 화면에 맞게 축소).
- 결과 화면은 5초 유지되며 다음 판이 자동으로 시작됩니다. 방장은 결과 중 새 게임 준비를 선택할 수도 있습니다.
- 각 플레이어는 전체 경기 동안 **500초 누적 판단시간**을 보유하고, 자신이 베팅하는 차례에만 시간이 줄어듭니다. 남은 시간과 차례 제한시간을 표시합니다.
- 누적 500초를 모두 소진해 제한시간이 종료되면 자동으로 포기하고, **이후 매 차례 20초의 추가 판단시간**이 제공됩니다. 해당 20초도 초과하면 자동 포기합니다.
- 자동 포기는 일반 포기와 동일하므로 10 카드를 들었다면 기존 **10 포기 패널티**도 적용됩니다. 새 게임을 열면 누적 판단시간도 초기화합니다.
- 기존 코인 버튼식 베팅, 20장 덱 교대, 남은 카드 수, BGM은 그대로 유지합니다.

## v1.6.2 — 인디언포커 버튼식 베팅 개선

## 게임 진행

1. 방 생성 → 초대 링크 복사 → 친구들 입장 → 전원 **준비 완료** → 방장 **게임 시작** (2~16명)
2. 52장 섞기. 맨 위 **16장**을 4×4로 뒷면 배치해 **5초 대기**
3. 해당 16장을 **20초 동안 공개**해서 외운 후 다시 뒤집음
4. 남은 덱의 맨 위 **3장을 공용 카드**로 공개
5. 모든 플레이어가 **15초 내에 16개 위치에서 2개 선택**. 카드는 최종 선택 시점까지 뒷면이고, 각자의 선택 내용은 결과 공개 전까지 비공개
6. **공용 3장 + 각자 선택한 2장**으로 정확히 5장의 표준 포커 족보 대결
7. 우승/공동 우승 발표 → **누적 승수 갱신** → 방장 **바로 다음 판 시작** 버튼으로 로비 없이 재경기 (또는 **대기실로 돌아가기**)

### 새 기능: 승수 기록 및 즉시 재시작 (v1.1)

- 참가자 목록을 누적 승리 횟수가 높은 순서대로 표시하고, 결과 화면에도 각자의 **누적 N승 / 참여 N판**을 보여줍니다.
- **공동 우승한 플레이어는 각자 1승**이 올라갑니다. 같은 라운드가 중복 집계되지 않도록 서버가 결과를 한 번만 확정합니다.
- 결과 발표 뒤 **방장만** `↻ 바로 다음 판 시작`을 누를 수 있습니다. 모든 플레이어에게 즉시 새로 섞은 카드가 배치되며 기존 **5초 대기 → 20초 암기 → 10초 선택**이 이어집니다.
- 기존 방 코드, 초대 링크, 참가자, 누적 승수는 그대로 유지됩니다. 이전 판에 관전으로 들어온 참가자도 다음 판에 자동 참여합니다.
- 준비 여부를 다시 확인하고 싶은 경우 방장이 `대기실로 돌아가기`를 누르면 기존처럼 전원 준비 후 시작할 수 있습니다. **대기실로 가도 승리는 유지됩니다.**
- 승수와 참여 판수는 현재 방에서만 유지되는 **서버 메모리 정보**입니다. 방 삭제·퇴장 또는 Render 서버 재시작/재배포 후에는 복원되지 않습니다. 새 버전을 처음 배포할 때 현재 방 정보는 초기화됩니다.

### 확정한 운영 규칙

- 서로 다른 참가자가 **같은 위치**를 선택할 수 있습니다. (각자의 선택권이 독립적)
- 한 플레이어는 **서로 다른 두 위치**를 선택합니다. 10초 동안 재선택 가능
- 선택을 안 했거나 1장만 선택한 참가자는 남은 자리를 **자동 무작위 선택**합니다.
- 게임 도중 입장한 사람은 해당 판 **관전**, 다음 판부터 참가 가능합니다.
- **금전 베팅 없음**, 5장 포커(스트레이트 플러시/포카드/풀하우스/플러시/스트레이트/트리플/투페어/원페어/하이카드), 동점이면 공동 우승. A-2-3-4-5는 5 하이 스트레이트, 무늬 우열 없음.
- 16장과 공용 3장은 같은 52장 덱에서 중복 없이 뽑습니다.

## 인터넷 링크로 배포 (Render 예시)

서버가 필요한 게임이므로 단순 HTML 파일을 공유하거나 GitHub Pages에 올리는 것으로는 다중 기기 실시간 플레이가 불가능합니다.

1. 소스 파일 전체를 GitHub 비공개 또는 공개 저장소에 올립니다.
2. Render의 **New → Web Service**에서 저장소를 연결합니다.
3. Runtime: Node, Build Command: `npm install`, Start Command: `npm start` (또는 리포지토리의 `render.yaml` 사용).
4. 생성된 `https://서비스주소.onrender.com` 등 배포 URL을 친구들과 공유합니다.
5. 화면에서 **새 게임 방 만들기**를 누른 뒤 **초대 링크 복사**를 사용합니다.

> Render 무료 Web Service는 유휴 상태에서 15분 후 잠들고 재시작 시 메모리에 있던 방이 사라질 수 있습니다. 실제 플레이 중에는 브라우저가 열려 있을 때 3분마다 경량 접속 확인을 수행합니다. 요금/휴면 정책은 실제 배포 시 확인하세요.

## 파일 구조

- `server.js`: 의존성 없는 Node HTTP + SSE 실시간 전송 서버, 닉네임/초대 코드/방장/라운드 관리
- `lib/game.js`: 서버에서 독점적으로 처리하는 타이머·배포·선택·승부 흐름
- `lib/poker.js`: 공정한 카드 섞기(암호학적 난수) 및 표준 포커 족보 비교
- `public/`: 모바일 및 PC를 위한 한국어 UI
- `test/`: 카드/족보/타이머 등 자동 테스트

## 주의 / 확장

- 현재 방과 참여자 정보는 **서버 메모리**에만 저장됩니다. 재시작/재배포 때 사라집니다. 장기 운영 시 Redis 같은 외부 저장소가 필요합니다.
- 서버를 **복수 인스턴스**로 띄우면 방 정보가 공유되지 않습니다. 단일 인스턴스로 배포해야 합니다.
- 게임은 SSE(EventSource)를 통한 푸시 동기화 방식입니다. 브라우저마다 타이머는 서버 기준으로 표시하고, 카드 내용/선택 결과는 서버가 관리합니다.
- 6시간 동안 변경이 없는 방은 서버에서 자동으로 정리합니다.
- 링크를 가진 누구나 입장할 수 있고, 접속자 닉네임은 공개됩니다. 친구들 간 소규모 게임용입니다. 공개 서비스 운영 시 비밀번호, 속도 제한, 영구 저장소, 모니터링 추가를 권장합니다.
